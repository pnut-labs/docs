# pnut-os developer documentation

The source of <https://pnut-labs.github.io/docs/>: how pnut-os is built
and tested, its interfaces, why things are as they are, and the traps
found on the way. Built with [Zensical](https://zensical.org); see
[Writing these docs](docs/writing.md) to build it and for its conventions.

The Interfaces pages are written at build time from pnut-os's `.proto`
files by `tools/proto_pages.py`; edit the comments there.

Apache-2.0, as pnut-os.
